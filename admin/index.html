Settings

Change Admin Password

Your password is managed securely in your Vercel project settings — not stored in this browser.

  1. Go to vercel.com/dashboard
  2. Open your project → Settings → Environment Variables
  3. Update the ADMIN_PASSWORD variable
  4. Click Save — the new password works immediately
How Publishing Works
  1. You save a change in this admin panel
  2. It's committed to the website's GitHub repository
  3. Vercel detects the change and rebuilds the website
  4. Goes live in about 1 minute
Adding More Admins

Currently one admin account is supported. To add another:

  • Go to Vercel → Settings → Environment Variables
  • Share the ADMIN_EMAIL and ADMIN_PASSWORD values with trusted volunteers
